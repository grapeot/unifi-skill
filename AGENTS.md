# AGENTS.md — unifi-skill

## Fixed contracts (do not change without updating everything together)

- **READ-ONLY is the product.** Every request primitive is a GET; the
  transport module exposes no POST/PUT/DELETE and a unit test
  (`test_no_http_write_methods_in_src`) enforces it. Never add configuration
  capability — SSID/RF/firmware/client-blocking changes belong to the
  controller UI. Proposals to add writes belong in `docs/rfc.md` as a future
  decision, not in code.
- Exit-code contract: 0 ok / 2 usage / 10 auth / 12 rejected-no-data /
  13 network-server. Changing it requires README.md,
  `skills/skill_unifi.md`, `src/unifi_skill/exitcodes.py`, and the tests to
  change in the same commit.
- Output envelope `{command, input, data}` on stdout for `--json` and for all
  error paths. Human tables are the no-flag default. stdout carries payload
  only; warnings to stderr.
- v2 endpoint trap: the SSID list is
  `/v2/api/site/{site}/wlan/enriched-configuration`. A plain GET
  `/v2/api/site/{site}/wlan` returns 404 on this controller generation.
- Radio client counts and CU live in `radio_table_stats` (device rows), not
  `radio_table` (which holds desired config: channel auto/manual, ht modes).
- AP change warm-up: after any controller-side AP change, retransmit and CU
  figures are distorted for ~30 minutes. Never treat that window as a
  baseline (docs/rfc.md D8).
- Default branch is `master`. Working language: English.

## Privacy (public repo)

- Never commit: real cookies, `.env`, export snapshots (`tmp/` is
  gitignored), or real network identifiers. `fixtures/` are generated by
  `scripts/capture_fixtures.py` through a redactor; regenerate rather than
  hand-patching, and keep the `_meta` note honest.
- Docs/examples use fake handles only: `https://192.0.2.10:11443`,
  `home-main` / `home-iot` SSIDs, `AP-1`.. names, `02:00:...` pseudo MACs,
  `op://your-vault/your-item/your-field`.
- Pre-push scan (must be zero matches on tracked files; the pattern itself
  lives in `scripts/privacy_scan.sh`, run it, don't inline it):
  `scripts/privacy_scan.sh`

## Layout

- `src/unifi_skill/` — package; `cli.py` argparse+commands, `transport.py`
  single GET primitive (read-only invariant lives here), `normalize.py` pure
  fixture-testable transforms, `envelope.py` output+renderers, `env.py`
  .env/cookie/config, `exitcodes.py` the contract.
- `scripts/` — `capture_fixtures.py` (maintainer tool, anonymizing).
- `tests/` — `test_unit.py` (offline, default), `test_integration.py`
  (opt-in `RUN_UNIFI_INTEGRATION=1`).
- `skills/skill_unifi.md` — the public agent skill document.
- `docs/` — prd / rfc / test / working / cookie_refresh.

## Working discipline

- Update `docs/working.md` (Changelog + Lessons Learned) in every session
  that changes code or discovers a real trap.
- Offline unit tests must run without network, keys, or a controller.
- Integration tests must skip cleanly when `RUN_UNIFI_INTEGRATION` is unset.
